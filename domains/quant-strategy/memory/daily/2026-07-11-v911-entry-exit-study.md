# 2026-07-11 V9.1 入场与止损受限消融

范围：2026-05-01 至 2026-07-10；仅使用健康来源反事实回放。固定可信事件门槛（来源完整度至少 15、基本面验证至少 10、非回填）、技术权重 `1.6`、总分门槛 `75`、Rule E 与 0.1% 单边成本。比较四种入场路径（any、breakout、pullback、trend）及三种退出方案：

- `current`：8% 初始止损、MA20 跟踪、3 日观察期限；
- `tight`：6% 初始止损、MA20 跟踪、3 日观察期限；
- `patient`：10% 初始止损、MA50 跟踪、5 日观察期限。

## 结果

| 代表版本 | 收益 | 最大回撤 | 买入 | 止损卖出 | 资讯净贡献 |
| --- | ---: | ---: | ---: | ---: | ---: |
| any + current | `+3.80%` | `-4.12%` | 6 | 3 | `-0.78%` |
| any + patient | `+3.94%` | `-4.12%` | 3 | 1 | `-0.63%` |
| breakout + tight | `+4.34%` | `-4.12%` | 2 | 1 | `-0.18%` |
| pullback（任意退出） | `+4.51%` | `-4.12%` | 0 | 0 | `0.00%` |

完整 12 组结果见 `results/v91_entry_exit_study_metrics.json`。

## 解释

最好的总收益来自 pullback 路径，但它没有发生任何资讯交易，不能称为买入/止损优化。最好的有交易版本是 `breakout + tight`：它只交易 MU 与 SNDK，资讯损失约 `-0.18%`，优于原 V9.1 的 `-0.78%`，但仍没有正贡献或回撤改善。

COHR、AMD、STX 等损失来自 `any/trend` 路径放行的弱趋势确认；当前样本显示，入场路径收紧比把初始止损从 8% 微调到 6% 或 10% 更有影响。

## 判定

建立 `V9.1.1 breakout-tight` 作为前向影子候选：可信事件资格、技术权重 1.6 与 75 分门槛保持不变；仅接受 breakout 路径；初始止损 6%、MA20 跟踪止损、3 个交易日观察期限。它不替代 V9.1，也不晋升为正式规则，原因是仅有 2 笔入场、1 笔止损，样本不足。

支持文件：`strategies/research-archive/v9-variants-results/v91_entry_exit_study_report.md`。

## 动态技术止损复核

新增 `technical_staged` 影子模式：固定 6% 仅作灾难保护下限；入场止损优先参考 MA20/事件低点减半个 ATR；未达到 `+1R` 时维持结构风险线，达到 `+1R` 后上移至保本与上升 MA20-1ATR 的较高者，达到 `+2R` 后使用上升 MA20-0.5ATR（或走弱时 MA50-1ATR）、最高价-2.5ATR 与保本线的较高者。止损永不下调。

在本次样本中，`breakout-tight + technical_staged` 与固定版完全相同：两笔交易均未先达到 `+1R`，动态止损没有进入保本或趋势跟踪阶段。`any/trend + technical_staged` 的资讯净贡献则从 `-0.78%` 恶化到 `-0.87%`，没有改善。因此动态模式保留为工程可用的前向影子机制，但不替换当前 `V9.1.1 breakout-tight` 候选。
