# SPY/QQQ 回撤情景笔记核验（2026-07-11）

核验对象：`2026-07-11-spy-qqq-drawdown-forecast.md`。结论：该笔记可保留为
**条件情景与监控清单**，但不能作为带有校准概率的回撤预测，也不能用于修改 V9
执行规则。

## 已确认正确

- 使用的 2000-01-03 至 2025-12-30 调整后收盘价，复算得到 CAGR：SPY `8.06%`、
  QQQ `8.19%`；最大峰谷回撤：SPY `-55.19%`、QQQ `-82.96%`。这些与统计文件一致。
- 完整事件检测结果中，`>=8%` 的事件数为 SPY `12`、QQQ `16`；`>=12%` 为 `7`、`10`；
  `>=20%` 为 `4`、`5`。
- 以 2026-07-10 本地 `data_v9/close.csv` 的收盘价复算，SPY `754.95`、QQQ
  `725.51` 正确。7/14 CPI、7/28-29 FOMC、7/30 PCE、8/7 就业报告、8/12 CPI、
  9/4 就业报告、9/11 CPI、9/15-16 FOMC 的日期与 BLS、Fed、BEA 官方日程相符。

## 不成立或需要改写的部分

1. 统计口径混用。原始 JSON 的 `>=8%` 全事件中位回撤实际为 SPY `-15.9%`（42
   日）、QQQ `-13.8%`（27 日），不是笔记所写的浅回撤区间。阈值筛选的是已经发展
   成至少 8% 的回撤，不能用来描述一般的 5%-10% 牛市回调。
2. “牛市回调”分类失真。原始分类只检查**峰值日**是否高于 MA200；因此 SPY 的
   2007-10 至 2009-03、2020 COVID、2022 熊市，以及 QQQ 的 2018 Q4、2020、2022
   等后来跌破 MA200 的事件被划为 `bull_pullback`。该样本不能支撑“趋势未破时多数
   回调的中位数/持续时间”的结论。
3. 用更严格的事后定义（峰值和谷值均在 MA200 之上，且回撤至少 5%）重算：SPY
   `n=10`，中位回撤 `-5.83%`、中位持续 `21.5` 个自然日；QQQ `n=12`，中位回撤
   `-7.75%`、中位持续 `25` 个自然日。它支持“QQQ 通常比 SPY 深”的方向性判断，
   但样本小，且是事后识别，不能保证下一次回撤的深度或时点。
4. 三情景的 `45% / 40% / 15%` 没有可复现的频率估计、条件变量模型或样本外校准，
   因而是主观权重，不是概率预测。应标为“风险预算情景”，不得以此推导交易胜率。
5. 情景点位有算术不一致：以 SPY `754.95` 计，`-5%~-8%` 是 `717.20~694.55`，
   基本正确；QQQ `725.51` 的 `-6%~-10%` 应为 `681.98~652.96`，不是 `700~653`。
   QQQ `-12%~-20%` 应为 `638.45~580.41`，不是以 `645` 为上沿。
6. 2026-07-10 的均线需统一为标准交易日滚动均线：SPY MA50/150/200 为
   `739.91 / 699.61 / 691.09`；QQQ 为 `714.59 / 646.42 / 636.63`。原笔记的收盘价
   正确，但均线值并非同一计算口径。

## 可保留的执行含义

- 只把 MA150/MA200、Fear Gate、完成收盘价和 V9 风险上限当作执行条件。
- 把 `~5.8%`（SPY）与 `~7.8%`（QQQ）理解为严格“趋势未破”历史样本的描述统计，
  不是买入目标、止损或价格预测。
- 若需要概率化情景，必须预先定义状态变量（趋势、波动率、估值/盈利、信用/广度），
  使用滚动样本外校准并报告置信区间；在此之前，保留为不下单的研究笔记。
